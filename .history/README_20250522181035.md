# Neural Vision - Advanced Computer Vision Demo

🚀 **[Live Demo](https://YOUR_USERNAME.github.io/neural-vision/)** | 🎥 **[Video Demo](https://YOUR_VIDEO_LINK)**

A multi-model computer vision demo that runs entirely in your browser. Experience real-time pose estimation, face detection, and hand tracking with stunning cyberpunk visual effects.

## 🌟 Features

### Three Neural Networks Running Simultaneously
- **Pose Estimation** - 17-point full body skeletal tracking using MoveNet
- **Face Detection** - Multi-face detection with MediaPipe
- **Hand Tracking** - 21-point hand skeleton with 3D depth visualization

### Stunning Visual Effects
- **Particle Physics System** - Dynamic particles that follow detected features
- **Multiple Visual Modes**:
  - 🔷 **Cyber** - Neon cyberpunk aesthetics
  - 🟢 **Matrix** - Digital rain effect
  - 🔵 **Hologram** - Futuristic scanning visualization
  - 🟣 **Neural** - Neural network inspired gradients

### Performance Optimized
- Achieves 30+ FPS on modern devices
- Parallel model inference
- Real-time performance metrics
- Efficient particle system

## 🛠️ Technical Details

### Technologies Used
- **TensorFlow.js** - Running neural networks in the browser

## 🎨 Customization

### Adjusting Effects
Edit the `getEffectColor()` function in `index.html` to customize colors:

```javascript
const colors = {
  cyber: { pose: '#00ffcc', face: '#ff00ff', hand: '#00ccff' },
  matrix: { pose: '#00ff00', face: '#00ff00', hand: '#00ff00' },
  // Add your own color schemes here
};
```

### Performance Tuning
Modify these values for performance optimization:

```javascript
this.maxParticles = 200; // Reduce for better performance
this.confidenceThreshold = 0.3; // Increase to reduce detections
```
